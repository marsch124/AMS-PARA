# Training plan

## Summary

Eight week plan, three runs per week, one long run at the weekend that grows from 5 km to 10 km.

## Key points

- Week 1: 3 km, 3 km, 5 km long run
- Week 4: 4 km, 5 km, 7 km long run
- Week 8: 3 km, 3 km, race
